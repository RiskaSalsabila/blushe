BLUSHÉ — PROTOTYPE AWAL SISTEM REKOMENDASI BLUSH ON

Cara membuka:
1. Ekstrak folder ZIP (jika memakai ZIP).
2. Buka file index.html dengan Chrome, Edge, atau Firefox.
3. Klik "Mulai rekomendasi" dan ikuti empat langkah input sampai halaman hasil.
4. Klik "Lihat detail" pada kartu produk untuk membuka contoh detail.

Catatan penting untuk bimbingan:
- Ini prototype front-end interaktif, belum aplikasi final.
- Belum ada backend, database, login, atau dashboard admin fungsional.
- Nama merek, produk, shade, harga, dan urutan rekomendasi merupakan DATA SIMULASI.
- Hasil belum dihitung dengan VIKOR. Tidak ada nilai Q/S/R aktual.
- Skin tone, undertone, kriteria, bobot, definisi preferensi warna, serta penggunaan harga sebagai filter/kriteria masih perlu divalidasi melalui studi literatur dan arahan dosen.
- Formula diperlakukan sebagai filter berdasarkan pilihan pengguna dalam prototype ini.

Tujuan prototype:
Meminta masukan dosen tentang alur pengguna, input yang diperlukan, output rekomendasi, dan ruang lingkup aplikasi sebelum implementasi sistem sesungguhnya.
